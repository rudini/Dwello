- Seite neu geladen, nachdem der Code erstellt war: Code und Download-Link waren noch da. Gut so.
- Die Bestätigung hat den Code auch in Kleinbuchstaben und mit Leerzeichen statt Bindestrichen angenommen, so wie der Hilfetext es verspricht.

Ich war kurz unsicher, ob ich noch etwas tun muss. Wer da nochmals klickt, erstellt aus Versehen gleich den nächsten Code.

## Aufgabe geschafft: ja

Zu den drei Fragen der Aufgabe:
- **Wofür ist der Code?** Ja, jetzt verstanden: Mit ihm lässt sich eine Sicherung meiner Daten lesen, etwa nach einem Defekt.
- **Was bedeutet es, dass mein Blatt weg ist?** Grösstenteils verstanden: Die bisherigen Sicherungen kann niemand mehr für mich öffnen, und wer das Blatt findet, kann sie bis zu 12 Monate lang lesen.
- **Soll ich einen neuen Code erstellen?** Ja, aber nur selbst gefolgert (P-1). Auf der Seite selbst steht es nicht.

Code erstellt, Notfallblatt heruntergeladen (`Notfallblatt-Dwello.pdf`, enthält den Code), Code bestätigt.

## Aufwand

Etwa 6 Minuten, 9 Schritte: Anmelden, Einstellungen, Karte «Neuer Wiederherstellungscode», Einleitung lesen (dreimal, P-2), Passwort eingeben, «Neuen Code erstellen», Seite neu laden, «Notfallblatt herunterladen (PDF)», Code eingeben und «Neuen Code bestätigen».

## Vorschläge

- **P-1:** Einstellungen › «Neuer Wiederherstellungscode» öffnen und die Einleitung lesen. Hilfreich wäre ein eigener Satz für den Fall «verloren», etwa: «Haben Sie es verloren, erstellen Sie jetzt einen neuen Code: Dann lassen sich Ihre Daten ab morgen wieder wiederherstellen.»
- **P-2:** Gleiche Stelle. Hilfreich wäre die Aufteilung in drei kurze Absätze: wofür der Code ist; «Haben Sie das alte Blatt noch: …»; «Haben Sie es verloren: …». Dazu kurze Sätze ohne Strichpunkt.
- **P-3:** Gleiche Stelle, vierter Satz. Hilfreich wäre z. B. «ob ihre Kopie der Sicherungen auf dem anderen Gerät sie länger behält», wie im Notfallblatt.
- **P-4:** Gleiche Stelle, letzter Satz. Hilfreich wäre der Satz, ob ich dagegen etwas tun kann, etwa: «Wollen Sie das verhindern, bitten Sie die Person, die Dwello betreut, die alten Sicherungen zu löschen.» Oder ausdrücklich, dass ich nichts tun muss.
