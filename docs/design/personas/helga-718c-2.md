## Beobachtungen

- Die Frage aus dem ersten Lauf ist beantwortet. Der Satz direkt unter dem Code sagt, dass ich bestätigen muss, wie lange ich Zeit habe (30 Minuten) und was passiert, wenn ich aufhöre: «sonst verfällt er und der bisherige Code gilt weiter». Damit verstehe ich: ohne Bestätigung nützt das neue Blatt nichts. Ganz ausdrücklich steht das aber nicht da («Das neue Notfallblatt gilt erst, wenn Sie bestätigen»), ich musste es mir selbst zusammenreimen.
- Auch auf dem Notfallblatt (PDF) steht: «Er gilt für die Sicherungen ab dem Tag, an dem Sie ihn in Dwello bestätigt haben.» Das ist gut. Auf dem Papier sehe ich später aber nicht, ob ich ihn wirklich bestätigt habe.
- Ich habe nach dem Erstellen aufgehört, mich neu angemeldet und die Seite wieder geöffnet. Dwello zeigte denselben Code mit dem Herunterladen und dem Feld zum Bestätigen wieder an. Das hat mich beruhigt. Die Übersicht sagte nach dem Neuanmelden nichts über einen offenen Code. Wer nicht von selbst auf die Seite zurückkehrt, merkt es dort nicht.
- Wie viel von den 30 Minuten noch übrig ist, sieht man nicht, auch keine Uhrzeit, bis wann.
- Für das Feld «Wiederherstellungscode erneut eingeben» habe ich den Code in Kleinbuchstaben und mit Leerzeichen statt Bindestrichen eingetippt. Dwello hat ihn angenommen, wie es der Hilfetext verspricht.
- Nach dem Bestätigen steht oben eine grüne Meldung mit Haken: «Der neue Wiederherstellungscode gilt ab jetzt. …». Gleich darunter stehen wieder das Passwortfeld und die blaue Schaltfläche «Neuen Code erstellen». Ich war kurz unsicher, ob ich noch etwas tun muss.
- Der lange Absatz oben («Die Sicherungen von vorher lassen sich weiterhin nur mit dem alten Code lesen …») steht schon vor dem Erstellen da und auch nach dem Bestätigen noch. Er ist lang, aber verständlich. «Die Person, die Dwello betreut» kenne ich nicht, ich mache das selbst.
- Bei 150 % gibt es auf der Seite keine Spalte und kein seitliches Scrollen. Der Code steht gross und gut lesbar da.

## Aufgabe geschafft: ja

## Aufwand

Etwa 6 Minuten, 11 Schritte: anmelden, Menü öffnen, «Einstellungen» wählen, die Karte prüfen, die Karte öffnen, das Passwort eingeben, «Neuen Code erstellen» drücken, den Hinweis lesen, abbrechen und neu anmelden (das Aufhören geprüft), das Notfallblatt herunterladen, den Code eingeben und bestätigen. Als Menü-Fehlgriff zählt einmal, dass ich zuerst den Link «Eine KI wählen Sie unter «Einstellungen» › «KI»» auf der Übersicht für den Menüpunkt hielt.

## Ablauf

- Einstellungen, Karte bei 150 %. Erwartet: Text in der Karte, ganz lesbar. Gesehen: Alles bleibt innerhalb der Karte. Das Wort wird aber als «Wiederherstellungs» / «code» ohne Trennstrich getrennt (P-1).
- Nach «Neuen Code erstellen». Erwartet: zuerst «drucken», dann «bestätigen». Gesehen: Der Text beginnt mit «Bestätigen Sie … innerhalb von 30 Minuten» und nennt das Drucken erst im dritten Satz (P-2). Die Reihenfolge der Schaltflächen stimmt (zuerst Herunterladen, dann Bestätigen).
- Nach dem Neuanmelden. Erwartet: ein Hinweis auf der Übersicht, dass noch ein Code auf die Bestätigung wartet. Gesehen: kein Hinweis. Erst auf der Seite «Neuer Wiederherstellungscode» war der offene Code wieder da.
- Nach dem Bestätigen. Erwartet: eine Erfolgsmeldung, sonst nichts mehr zu tun. Gesehen: die Erfolgsmeldung und darunter gleich wieder das Formular «Neuen Code erstellen».

## Vorschläge

- **P-1:** Anmelden, Menü › «Einstellungen», zum Abschnitt «Sicherung» scrollen (1440 × 900, 150 %). Die Karte ist rund 229 CSS-px breit. Titel und Text trennen «Wiederherstellungs|code» ohne Strich. Hilfreich wäre eine richtige Silbentrennung mit Strich (z. B. Trennung nach der Sprache der Seite) oder eine breitere Karte, wenn rechts daneben Platz frei ist.
- **P-2:** Auf «Neuer Wiederherstellungscode» das Passwort eingeben und «Neuen Code erstellen» drücken, dann den Hinweis unter dem Code lesen. Hilfreich wäre ein Text in der Reihenfolge der Arbeit, zum Beispiel: «1. Laden Sie das Notfallblatt herunter und drucken Sie es aus. 2. Geben Sie den Code unten ein und bestätigen Sie ihn innerhalb von 30 Minuten. Erst dann gilt das neue Blatt; ohne Bestätigung verfällt der neue Code und der bisherige gilt weiter.»
