# Native reads – French, Italian, English

One read-only subagent per file, each acting as a Swiss native speaker (Suisse romande, Ticino, English speaker living in Switzerland). **No human native speaker has checked the translations.** Every quoted button label in the help texts matched the real buttons in all three files.
