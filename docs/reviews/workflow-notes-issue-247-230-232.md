| Skill `pull-request`, "Which pull requests" («a request that covers several issues gets one pull request per issue») | The coordinator asked for one pull request with `Fixes #n` per issue. The three issues change the same stored field (`heating_share`), the same PDF section and the same tests in one commit. Splitting would have meant three branches on top of each other.
