# Workflow notes: #1240, #1241, #845 (CI runners)

One request, three issues in a row, each with its own pull request (#1243, #1250, #1251), all changing `.github/workflows/ci.yml`.

| Rule | What happened | Proposed change |
|---|---|---|
| Skill `pull-request`, «Open and drive» (auto-merge «once nothing but CI is left») | Twice auto-merge did not merge: on #1243 it stayed armed after the owner changed the ruleset (GitHub only re-evaluates on a check event), and on #1250 GitHub refused to arm it («Pull request is in clean status») because nothing was left to wait for. Both times the session merged by hand. | Say: when the pull request is already `clean` (or turns `clean` without a new check event), merge it with a merge commit instead of arming auto-merge. |
| Skill `pull-request` (a blocked pull request with every check green) | #1243 was `blocked` with all checks green; the ruleset is not readable from a session (API 403, GraphQL off). The session guessed «branch must be up to date», merged `main` and spent a full CI run before finding the real cause: the four removed jobs were still required checks (the merged pull requests #1214, #1218 had them, and were 38 and 20 commits behind). | Add: before merging `main` into a green but blocked pull request, compare its check names with those of the last merged pull request; a name it lacks is a required check the owner must change. |
| Skill `issue-work`, second bullet («The pull request says `Fixes #n`») | #845's «Done means» ends with a measurement over 10 merged pull requests, which no pull request can hold. The session used `Refs #845` and left the issue open, which the outside review then flagged against the archive text. | Allow `Refs #n` when a «Done means» bullet can only hold after the merge (a measurement), and say the issue stays open for it. |
| Skill `pull-request`, «Before each push», 2 (closing review for any change under `tools/`) | A change of only the four test titles to German (answering an outside-review Low) needed a `code-reviewer` round of its own before the push; it found nothing. | Exempt a change of test titles only (no code, no assertion) like reports and the plan. |
