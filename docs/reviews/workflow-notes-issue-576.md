# Workflow notes: #576 (Konto mit Passwort, PR #591)

| Rule | What happened | Proposed change |
|---|---|---|
| `.claude/hooks/commit-msg-gate.mjs` (commits with `-F` pass unchecked) | As in `implementation_plan.md` (session 2026-10-21, «the local commit-msg hook let `git commit -F -` through»). New: it happened again on #591 (52 characters). The only fix was to reword the commit, which needed a force-push and the product owner's approval. | Check `-F -` and `-F <file>` as well. Or have the `pull-request` skill, "Before each push", run the same loop over `origin/main..HEAD` that CI's «Commit subjects» step runs. |
| `CLAUDE.md`, "Before marking anything complete", and Gotchas "Formatting" | "Formatting" says to run `prettier --write` on files you create. "Before marking anything complete" does not list that check, but CI's «Lint and types» runs `prettier --check` on every added file. Two new files failed there and cost one CI round. | Add `git diff --name-only --diff-filter=A -z origin/main...HEAD \| xargs -0 -r bunx prettier --check --ignore-unknown` to "Before marking anything complete". |
| `pull-request` skill, "Red CI" | The summary jobs «E2E tests» and «Axe» counted green shards through the Actions API and stayed red with every shard green, the re-run included. Another session fixed the same job at the same time on `main` (#595, retries); my fix (an early pass on `needs.e2e-tests.result`) then conflicted with it. | Before changing a shared CI workflow, fetch `main` and look at the open pull requests for a fix of the same job; port it, or build on it. |
| `.claude/agents/persona.md` and `slice-review` skill ("personas write `docs/design/personas/<persona>-<slice>.md` themselves") | Helga, Sven and Dr. Weber each said that their own instructions forbid report files, and wrote the report only because the task asked for it. | Have the persona agent's instructions name the report path the skill sets. |
| `CLAUDE.md`, "Done means" (a Minor stays in its report) | Helga, Anna and Marco each reported the same Minor: they did not understand «Betreiber Ihrer Dwello-Installation» in the forgotten-password help. By the rule it stays in three reports, with no issue and no fix. | A Minor that two or more personas meet in the same place counts as a Major, or at least becomes an issue. |
