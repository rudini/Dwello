# Dwello marketing site and brand

A proposal for the public website of Dwello as an open-source project, plus the brand manual it is built on. The brand is the app: same tokens (`src/styles/tokens.css`), Inter only, the app's header logo, Lucide icons, panels and badges. Static HTML, no build step, no external requests: Inter is self-hosted.

| Path | What |
|---|---|
| `index.html` | Landing page (German, the source of the other languages): hero with the statement PDF and its QR-bill, the landlord's year, three features (upload animation, statement screenshot, split animation; an animation plays once from its button, its texts are HTML next to the drawing), a short feature index (only what no other section names), install (commands collapsed for the helper), privacy, accessibility, FAQ, open source, roadmap (MCP included) |
| `brand.html` | Brand manual: brand core, logo, colour, typography, elements, images, tone of voice, messaging, strategic sitemap with SEO and launch plan, applications |
| `fr/`, `it/`, `en/` | The landing page in French, Italian and English, generated by `i18n/build.py` |
| `i18n/` | `build.py` and one table per language (German text → translation); terms per `docs/design/i18n-begriffe.md` |
| `shots/` | Screenshots of the app with the demo data, light and dark (WebP), and a statement PDF; `shots/{fr,it,en}/` the same in that language (PDF of a tenant who speaks it) |
| `assets/` | Logo (light, dark, inverse), app icon, wordmark; outlined SVG |
| `fonts/` | Inter, latin subset (SIL OFL 1.1) |
| `robots.txt`, `sitemap.xml` | Search engines: everything may be indexed; the sitemap lists the four landing pages with their language versions. A new page goes into `sitemap.xml` |
| `<32 hex>.txt` | IndexNow key (its name is also in `deploy-site.yml`): after each upload `deploy-site.yml` tells Bing, Yandex, Seznam, Naver and Yep the sitemap's pages. Google takes no IndexNow: register the site once in Google Search Console (and Bing Webmaster Tools, which can import it from there) and submit `https://dwello.ch/sitemap.xml` |

After changing German texts in `index.html`, add them to `i18n/{fr,it,en}.json` and run `python3 marketing/i18n/build.py`; it stops on a text it cannot find and lists German left in a translation.

Retake the screenshots after UI changes: `docs/design/tools/persona-stack.sh` starts the app with the demo data on :3300; capture at 1440 × 900 (DPR 2) and 390 × 844 (DPR 3), light and dark; the language comes from the cookie `PARAGLIDE_LOCALE`.

Features the page marks as "Geplant" do not exist in the app yet; each has an issue: MCP server #495, full export #496, one-step installer and local sign-in #497. Dwello is licensed AGPL-3.0-or-later (`LICENSE`).
