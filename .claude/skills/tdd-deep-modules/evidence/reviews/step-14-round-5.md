## Findings
- **[major]** harness/stage3:77, 179, 205-217; README.md:19 — `escapes()` still invalidates runs for ordinary work, hitting arm 3 hardest: EMBEDDED_PATH's lookbehind does not exclude `*`/`?`, so any glob with `*/` yields a "path" (`src/*/*.ts` -> `/*.ts`); slash-led grep patterns, test-name filters, commit and tdd-step messages and regex literals in `bun -e` probes count as paths (`/money`, `/100`, `/-/g`, `/[a-z]+/`), and a bare `'/'` grep pattern counts as "path /" although the README says a `'/'` literal does not count; `_command_words` splits into lines before quoting is parsed, so multi-line `-m` message bodies are parsed as commands; signal words are matched on the full JSON including heredoc bodies. These occur in this repository's own real sessions and the multi-module and parsing fixtures invite them; arm 3 makes several times more Bash calls, so its runs are invalidated and rerun more often and its valid sample is selected by working style. Fix: tokenise the whole command with newlines as separators only outside quotes; treat a token as a path only when its first component (fnmatch, so globs count) names a real top-level entry outside the allowed places (home root proc sys run var dev mnt srv boot media nix old_root sandbox verifier lost+found container_info.json) or it climbs out of /workspace after normalisation; a bare `/` only as an operand of cd/ls/find/du/tree/cp/ln/tar or the path operand of grep -r, never the pattern argument of grep/rg/sed; signal words only outside heredoc bodies; rerun all samples and document remaining false positives.
- **[major]** harness/stage3:673-677 — pilot rounds after the first are judged on the depth result: `if phase != "pilot": ok &= fx_ok` applies "skill deeper than baseline" to pilot2, pilot3, ...; demonstrated (a clean pilot2 with reliable controls prints PILOT: NOT OK because arm 3 scored lower; the main gate calls the same round ok). With README:38 (fix and pilot again after a failed pilot), repeating pilots and tuning the rubric would depend on arm 3 winning: bias toward arm 3. Fix: judge fx_ok only when phase == "main"; re-check with the fake pilot2.

Deliberate acts, visible in the transcript, network limit documented: not a major. Fix: check assignment values as paths; check echo/printf words; strip shell keywords and wrappers before the command-position test; scan `bash -c`/`sh -c` code recursively.
