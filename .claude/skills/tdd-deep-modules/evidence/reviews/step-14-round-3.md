## Findings
- **[major]** harness/stage3:66-72, 161-164, 265; README.md:21,27 — the foreign-reference rule invalidates runs for ordinary work (bare-slash alternative matches ` / ` and `'/'` in Bash/Grep inputs; `/tmp\b` matches Claude Code's own scratchpad; `/root/` matches overflow tool-result files the session is told to Read; `\bproxy` matches JS Proxy). Since invalid runs are rerun and only the first valid attempt counts, this selects runs by working style, which differs between arms; for a reviewer the same trigger fails the gate permanently. Fix: drop the bare `/` and `../..` heuristics or tie them to path-taking commands; exempt the session's own scratchpad_path and tool-results dir; keep invalidation for real escape signals only (URLs, proxy env vars, /proc/<pid>/{environ,root,cwd}, /home/, /root/ outside own dirs, /sandbox, /verifier, the experiment's names); gate prints invalid-attempt counts per arm and reason, reported in REPORT.md; a reviewer reference = incomplete review (rerun), not a permanent failure.
- **[major]** harness/stage3:441-459, 533-551; README.md:44 — slots are unconstrained: a fixture can be judged on any 3 reviewed slots (fake: r3 valid but unreviewed, r1, r2, r4 reviewed -> "n=3 ok"); depth_report findings in run records are visible before review, so an unfavourable slot can be dropped. Fix: in main require slots exactly {1,2,3} per fixture and arm; fail on runs in slots > 3 and on slots with runs but no complete reviewed group; groups r1..r3.
- **[minor]** harness/stage3:101-106, 174-175, 261, 301 — host-side git in measurement runs against arm-controlled repo config; filter.<x>.clean + .gitattributes executes on the host during status/ls-files/bundle (demonstrated); could alter other runs' trees. Fix: run them in_sandbox, or measure from a fresh clone of the bundle without the arm's .git/config.
- **[minor]** harness/stage3:112-113, 270-271; sandbox.sh:13-15 — /verifier binds the whole skill directory incl. evals/stage3/{fixtures,holdout} and results; arm code runs with that mount during tdd_replay. Fix: bind only SKILL/scripts.
- **[minor]** README.md:19-21; sandbox.sh:17 — network isolation is a tripwire, not a barrier (token files readable; proxy address in the Claude process's /proc/<pid>/environ; write-then-execute unscanned); README does not say so. Fix: hide /home/claude/.claude/remote except the file the ingress token variable needs; state the residual route.
- **[minor]** harness/stage3:543-566 — pilot not gated: `gate --phase pilot` exits 0 even with UNRELIABLE reviewers or < 2 fixtures x 3 arms; main gate never checks a reliable pilot. Fix: main gate requires a pilot with 2 reviewed fixtures and no UNRELIABLE control.
